# Net Drill

A daily practice site for computer networks and data center networking interviews.

Each calendar day serves 10 multiple-choice questions: 3 easy, 4 medium, and 3 hard. Every question is labeled with its toughness. At least two questions in the set are answered from a network diagram. The same ten stay up for the whole day. The bank has 1,000 questions and rotates every 100 days.

Progress is stored in the browser.

```bash
npm install
npm run dev
```

Open the URL Vite prints. `npm run build` typechecks and builds the static site.
